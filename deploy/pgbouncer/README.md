# PgBouncer — transaction pooler (Task 14.3.6)

`pgbouncer.ini` is the pooler configuration deployed to
`/etc/pgbouncer/pgbouncer.ini` on the PostgreSQL hosts (bare-metal path
per spec §19.13.1 — the postgres row co-locates the pooler with the
primary).

## Sizing contract

| Setting | Value | Why |
|---|---|---|
| `max_client_conn` | **100** | Task 14.3.6 cap. All service pgx pools summed must fit; connection storms queue at the pooler instead of exhausting `max_connections`. |
| `default_pool_size` | 20 | Per (db,user) server-side pool — sized to PG `max_connections` headroom, not client count. |
| `max_db_connections` / `max_user_connections` | 100 | Server-side ceilings mirror the client cap. |
| `reserve_pool_size` | 5 | Saturation burst allowance. |

Change the cap only with a capacity-model update — the service pools
(`EXC_POSTGRES_MAX_CONNS` per daemon) must remain inside it, and
PostgreSQL `max_connections` must keep headroom for admin sessions +
`max_wal_senders` (postgresql.conf sets 10 senders).

## Service wiring

- Unit: distro `pgbouncer.service` + the existing override
  `deploy/systemd/pgbouncer.service.d-override.conf` (Restart=always,
  `LimitNOFILE=1048576`, `SyslogIdentifier=pgbouncer`).
- Install (bare-metal, matches `deploy/baremetal/` conventions):
  ```sh
  install -o pgbouncer -g pgbouncer -m 0640 pgbouncer.ini /etc/pgbouncer/pgbouncer.ini
  install -o pgbouncer -g pgbouncer -m 0600 userlist.txt /etc/pgbouncer/userlist.txt  # generated by secrets pipeline
  install -d -o pgbouncer -g pgbouncer /var/log/pgbouncer /var/run/pgbouncer
  systemctl daemon-reload && systemctl enable --now pgbouncer
  ```
- `userlist.txt` never lives in the repo — rendered by the secrets
  pipeline (Phase-13.5 Task 13.5.3.5, Vault/KMS) like every other
  credential artifact.
- Services point their DSN at `host=127.0.0.1 port=6432` when co-located,
  or the pooler VIP on shared-pooler hosts — `EXC_POSTGRES_DSN` is the
  single source; no code change.

## Verification

```sh
psql -h 127.0.0.1 -p 6432 -U postgres pgbouncer -c 'SHOW CONFIG' | grep max_client_conn
# -> max_client_conn | 100
psql -h 127.0.0.1 -p 6432 -U postgres pgbouncer -c 'SHOW POOLS'
```
